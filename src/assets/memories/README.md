# Our Memories — photo gallery

Drop event photos here and they appear automatically on the **Our Memories** section and page.

## Folders

| Folder | Use for |
|--------|---------|
| `award-ceremony/` | Awards ceremony photos |
| `elevate-session/` | Elevate session & workshops |
| `_general/` | Any other Challenge Sphere moments |

Create new subfolders anytime — all images under `memories/` are picked up on build.

## Supported formats

`.jpg`, `.jpeg`, `.png`, `.webp`

## Tips

- Use descriptive filenames (e.g. `robotics-finals-2026-01.jpg`).
- Keep file sizes reasonable for web (under ~2 MB each when possible).
- Do **not** put organizing committee headshots here — those live in `team/`.

After adding files, save and refresh the dev server (or redeploy for production).
